# 🔄 Shape Shifter

An interactive and animated **Shape Shifter game** built with **React** and **Framer Motion**. Transform between different shapes with smooth SVG animations and enjoy a fun, interactive gaming experience.

## ✨ Features

- 🎨 Multiple unique shapes
- 🔄 Smooth shape transformation animations
- ⚡ Framer Motion powered animations
- 🧩 SVG-based shapes
- 🎮 Interactive gameplay
- 📱 Responsive design
- 🚀 Fast and modern React application

## 🛠️ Tech Stack

- **React** – Frontend library
- **Framer Motion** – Animations and transitions
- **JavaScript** – Game logic
- **SVG** – Shape rendering and morphing
- **CSS / Tailwind CSS** – Styling

## 🎯 Shapes

The game includes several shapes that can be transformed into each other, such as:

- 🔵 Circle
- 🟦 Square
- 🔺 Triangle
- 💎 Diamond
- ⬟ Pentagon
- ⬡ Hexagon
- ⭐ Star
- ❤️ Heart
- 🛡️ Shield
- ⚡ Lightning
- ⚙️ Gear
- 🛑 Octagon

More shapes can be added as the project evolves!
